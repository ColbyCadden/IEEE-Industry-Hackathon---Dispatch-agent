Calgary 311 Dispatch Agent — System Architecture

Autonomous dispatch for municipal road & waste tickets. Live 311 data → priority scoring → five optimised crew routes → SUMO simulation and a 3D city view.
The loop on the right is the point: a caller reports an update, and the plan re-optimises live.

Data flow & decision loop

Real, live

  • • 311 feed (city ArcGIS, 11 categories)
  • • Travel times & incidents
  • • Routing + OR-Tools optimisation
  • • ElevenLabs voice agent
  • • 3D viewer, click-to-fix

Mixed freshness

  • • Traffic counts: annual, 2002–2018
  • • 311 CSV: historic snapshot
  • • Travel time: free-flow from speed limits
  • • Not live congestion

Our assumptions

  • • Urgency scores (priority agent is a stub)
  • • Crew depot locations
  • • On-site work time per job type
  • • The cars in the sim are simulated
